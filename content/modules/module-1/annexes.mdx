# Conclusion & Annexes du Module 1

Ce premier module constitue le socle technique de toute la formation.

Il permet de comprendre et de maîtriser les interactions entre une application TypeScript et Google Gemini.

Les connaissances acquises seront réutilisées dans les modules suivants :
- **Le module 2** exploitera les capacités de Gemini pour construire des interfaces React augmentées par l'IA.
- **Le module 3** approfondira l'architecture backend et la gestion des API IA.
- **Le module 4** intégrera Gemini dans des workflows n8n.
- **Le module 5** utilisera Gemini pour construire des applications RAG avec Qdrant.
- **Le module 6** exploitera le tool calling pour développer des agents intelligents.
- **Le module 7** renforcera la sécurité et la fiabilité des applications.
- **Le module 8** réunira l'ensemble des compétences dans un projet professionnel.

**Résultat final :** être capable de développer de manière autonome des fonctionnalités IA avec Google Gemini, de les intégrer dans un backend TypeScript et de préparer leur utilisation dans des applications frontend professionnelles.

## ANNEXE A — COMMANDES ESSENTIELLES

Créer un projet :
```bash
npm init -y
```

Installer le SDK :
```bash
npm install @google/genai
```

Installer Express, dotenv, CORS et Zod :
```bash
npm install express dotenv cors zod
```

Installer TypeScript et les outils de développement :
```bash
npm install -D typescript tsx @types/node @types/express @types/cors vitest supertest @types/supertest
```

Démarrer en mode développement :
```bash
npm run dev
```

Compiler :
```bash
npm run build
```

Démarrer la version compilée :
```bash
npm start
```

Exécuter les tests :
```bash
npm test
```
