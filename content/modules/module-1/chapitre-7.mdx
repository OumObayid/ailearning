# Chapitre 7 — Analyser des images et des documents avec Gemini (La Multimodalité)

Jusqu'à présent, nous avons fait dialoguer notre serveur avec Gemini uniquement par écrit. C'est déjà impressionnant, mais c'est un peu comme discuter au téléphone dans le noir : l'IA ne voit rien de ce qui l'entoure !

Dans ce chapitre, nous allons donner **des yeux** à notre application. Grâce à la **multimodalité**, Gemini est capable d'observer des photos, de lire le texte sur un ticket de caisse froissé, de repérer un défaut sur un vêtement ou d'expliquer un schéma technique complexe.

Pas à pas, nous allons voir comment préparer une image avec Node.js et l'envoyer à Gemini pour qu'il l'analyse avec une précision remarquable.

---

### 1. Qu'est-ce que la multimodalité ?

Le mot **multimodal** signifie simplement *"capable de comprendre plusieurs modes d'expression"*.

Un humain n'utilise pas seulement des mots : il regarde des images, écoute des voix, lit des graphiques et regarde des vidéos.  
Les modèles de la famille Gemini ont été conçus dès le départ pour traiter simultanément :
- Du texte (des questions, des consignes).
- Des images (photos JPEG, PNG, captures d'écran).
- Des documents numérisés (factures, devis, fiches techniques au format PDF).
- De l'audio et de la vidéo.

---

### 2. Cas d'usage concrets en entreprise

Pourquoi la vision par IA révolutionne-t-elle le développement d'applications ?

- **La comptabilité sans saisie manuelle :** Un employé prend en photo son ticket de restaurant avec son smartphone. L'IA lit immédiatement le commerçant, la date, la TVA et le total TTC, puis remplit la note de frais toute seule !
- **L'e-commerce automatique :** Vous photographiez un meuble ou une paire de chaussures. L'IA rédige la description du produit, identifie sa couleur dominante, son matériau et son état.
- **L'accessibilité pour tous :** L'IA décrit précisément ce qui figure sur une image pour que les personnes malvoyantes puissent écouter la description grâce à un lecteur d'écran (balise `alt` en HTML).
- **Le dépannage technique :** Un utilisateur envoie la capture d'écran d'un message d'erreur ou la photo d'un voyant allumé sur son tableau de bord : l'IA identifie la panne et guide l'utilisateur.

### 4. Comment transmettre une image à Gemini en Node.js ?

Un fichier image n'est pas une simple phrase. C'est une suite d'octets binaires représentant des pixels de couleur.  
Pour transmettre une image à Gemini dans une requête, il existe deux manières simples :

1. **L'encodage Base64 (pour les images légères, moins de 10-20 Mo)** : On transforme les octets de l'image en une longue chaîne de caractères textuelle que l'on glisse directement dans la requête.
2. **Le service de fichiers (File API de Google)** : Pour les très gros fichiers (vidéos de plusieurs centaines de mégaoctets ou gros documents PDF), on téléverse d'abord le fichier chez Google puis on donne son adresse à Gemini.

Pour 95 % des besoins web et mobile du quotidien, **l'encodage Base64** est la méthode la plus rapide et la plus directe !

### 5. Exemple concret : Analyser une photo locale en TypeScript

Voici comment lire une image présente sur votre disque dur et demander à Gemini de la décrire :

<CodeBlock language="typescript" filename="src/services/vision.service.ts">
{`import { ai, GEMINI_MODEL } from "../config/gemini.js";
import fs from "fs";

/**
 * Lit un fichier image local et le transforme en objet Base64 pour Gemini
 */
function fileToGenerativePart(filePath: string, mimeType: string) {
  // 1. On lit le fichier sur le disque dur
  const fileBuffer = fs.readFileSync(filePath);

  // 2. On le convertit en texte Base64
  return {
    inlineData: {
      data: fileBuffer.toString("base64"),
      mimeType
    }
  };
}

export async function analyzeProductPhoto(imagePath: string) {
  // Préparation de l'image
  const imagePart = fileToGenerativePart(imagePath, "image/jpeg");

  // On envoie à la fois le texte d'instruction ET l'image à Gemini
  const interaction = await ai.interactions.create({
    model: GEMINI_MODEL,
    input: [
      {
        text: "Décris cet objet avec précision. Indique sa couleur, son état général et sa catégorie."
      },
      imagePart
    ]
  });

  return interaction.output_text;
}`}
</CodeBlock>

#### Ce qui se passe ici :
- `input` n'est plus seulement une simple phrase ! C'est maintenant un tableau qui contient **à la fois votre question textuelle ET votre image**.
- Gemini observe les pixels de l'image tout en lisant votre consigne, puis formule sa réponse exactement comme un être humain qui regarde une photo qu'on lui montre.

### 6. Les contrôles de sécurité obligatoires sur les fichiers

Dans une application en production, ne transmettez jamais un fichier à l'IA les yeux fermés ! Appliquez toujours ces 3 règles d'or :

1. **Limiter la taille maximale** : Bloquez les fichiers de plus de 5 ou 10 Mo pour ne pas saturer la mémoire vive de votre serveur.
2. **Vérifier le type MIME** : N'acceptez que des images légitimes (`image/jpeg`, `image/png`, `image/webp`).
3. **Se protéger contre les fichiers malveillants** : Vérifiez que l'extension correspond au contenu réel avant tout traitement.
