# Chapitre 8 — Le Streaming et les Appels d'outils (Function Calling)

Bienvenue dans l'un des chapitres les plus passionnants du cursus !  
Nous allons découvrir deux super-pouvoirs indispensables qui font passer vos projets d'une simple expérience de laboratoire à une véritable application d'entreprise professionnelle :

1. **Le Streaming** : Fini le sablier frustrant de 5 secondes pendant que l'IA réfléchit ! Les mots apparaissent à l'écran au fur et à mesure qu'ils sont rédigés, comme une machine à écrire magique.
2. **Le Function Calling (Appels de fonctions)** : Comment donner à Gemini les moyens d'agir dans le monde réel (consulter votre stock de produits, vérifier un suivi de colis ou calculer des frais de port réels).

---

### 1. Le Streaming : Pourquoi est-ce si important ?

Avez-vous remarqué que sur ChatGPT ou Gemini, vous n'attendez jamais 10 secondes devant une page blanche ? Les premiers mots commencent à s'afficher en une fraction de seconde !

C'est cela, le **Streaming** :
- **Sans streaming (l'effet sablier)** : Votre serveur attend que Gemini ait fini d'écrire son paragraphe de 500 mots avant d'envoyer quoi que ce soit au client. L'utilisateur a l'impression que le site rame ou est planté.
- **Avec streaming (le robinet ouvert)** : Dès que Gemini a rédigé les 2 premiers mots, Google vous les envoie aussitôt. Votre serveur les transmet instantanément à l'écran de l'utilisateur. L'expérience devient immédiate, vivante et ultra-fluide !

### 2. Activer le streaming avec l'Interactions API

Activer le streaming avec le SDK officiel est d'une simplicité déconcertante : il suffit de passer l'option `stream: true` !

<CodeBlock language="typescript">
{`const stream = await ai.interactions.create({
  model: GEMINI_MODEL,
  input: "Explique-moi les bienfaits du sport en 3 paragraphes.",
  // 🌊 On active le mode robinet ouvert !
  stream: true
});

// On lit les petits paquets de texte au fur et à mesure de leur arrivée
for await (const event of stream) {
  if (event.event_type === "step.delta" && event.delta.type === "text") {
    // Affiche le morceau de mot immédiatement sans sauter de ligne
    process.stdout.write(event.delta.text);
  }
}`}
</CodeBlock>

> **Que signifie `process.stdout.write(...)` ?**  
> Contrairement à `console.log()` qui saute automatiquement une ligne à chaque appel, `write()` colle les lettres les unes à côté des autres. Vous voyez le texte s'écrire en direct sous vos yeux dans votre console Node.js !

### 3. Diffuser le streaming vers le navigateur avec Express (SSE)

Pour que votre site web reçoive ces mots en direct, nous utilisons une technologie standard du web appelée **Server-Sent Events (SSE)**.  
C'est comme un tuyau d'arrosage qui reste ouvert entre votre serveur et le navigateur de l'utilisateur :

<CodeBlock language="typescript" filename="src/controllers/stream.controller.ts">
{`import type { Request, Response } from "express";
import { ai, GEMINI_MODEL } from "../config/gemini.js";

export async function streamController(req: Request, res: Response) {
  try {
    const { prompt } = req.body;

    // 1. On configure les en-têtes pour garder la connexion ouverte
    res.setHeader("Content-Type", "text/event-stream");
    res.setHeader("Cache-Control", "no-cache");
    res.setHeader("Connection", "keep-alive");

    // 2. On lance le stream auprès de Google Gemini
    const stream = await ai.interactions.create({
      model: GEMINI_MODEL,
      input: prompt,
      stream: true
    });

    // 3. Chaque petit bout de phrase reçu est immédiatement propulsé vers le client
    for await (const event of stream) {
      if (event.event_type === "step.delta" && event.delta.type === "text") {
        res.write(\`data: \${JSON.stringify({ text: event.delta.text })}\\n\\n\`);
      }
    }

    // 4. L'IA a fini de parler : on ferme le tuyau proprement
    res.write("event: done\\ndata: {}\\n\\n");
    res.end();
  } catch (error) {
    console.error("Erreur de flux :", error);
    res.end();
  }
}`}
</CodeBlock>

### 4. Le Function Calling : Donner des mains à l'intelligence artificielle

Gemini est un génie avec une mémoire colossale, mais il vit enfermé dans une bulle :
- Il ne connaît pas l'heure qu'il est en ce moment précis.
- Il ne sait pas si votre client Dupont a payé sa facture hier.
- Il ne peut pas aller chercher le stock d'un produit dans votre base MySQL.

C'est là qu'intervient le **Function Calling** (l'appel d'outils) !  
C'est la passerelle qui permet à Gemini de dire à votre serveur : *"Pour répondre à cet utilisateur, j'ai besoin que tu lances cette fonction avec ces paramètres !"*.

<Callout type="important" title="La règle fondamentale de sécurité">
**Gemini n'exécute JAMAIS de code directement sur votre machine.**  
L'IA vous tend simplement un petit papier disant : *"S'il te plaît, peux-tu exécuter la fonction `verifierCommande(125)` ?"*. C'est VOUS, et uniquement votre serveur backend, qui vérifiez si l'utilisateur en a le droit et qui lancez la requête SQL.
</Callout>

Voici les 4 étapes qui se déroulent en quelques millisecondes :

2. **Étape 2 :** Gemini comprend qu'il ne connaît pas cette information. Au lieu d'inventer, il répond à votre serveur : *"J'aimerais appeler l'outil `get_order_status` avec le paramètre `order_id = 102`"*.
3. **Étape 3 :** Votre serveur Node.js fait la recherche dans la base de données et trouve : *"En cours de livraison"*. Il renvoie cette réponse à Gemini.
4. **Étape 4 :** Gemini intègre cette information et rédige une phrase parfaite pour le client : *"Votre commande numéro 102 est actuellement en cours de livraison !"*.

### 6. Comment déclarer un outil en TypeScript ?

Pour que Gemini sache quels outils sont à sa disposition, vous lui fournissez un catalogue au format JSON :

<CodeBlock language="typescript">
{`// Le catalogue de l'outil
const getOrderStatusTool = {
  type: "function",
  name: "get_order_status",
  description: "Consulte le statut de livraison d'une commande à partir de son numéro.",
  parameters: {
    type: "object",
    properties: {
      order_id: {
        type: "integer",
        description: "Le numéro unique de la commande (ex: 101, 102)."
      }
    },
    required: ["order_id"]
  }
};`}
</CodeBlock>

On transmet ensuite cet outil dans l'appel :

<CodeBlock language="typescript">
{`const interaction = await ai.interactions.create({
  model: GEMINI_MODEL,
  input: "Bonjour, où en est ma commande 102 s'il vous plaît ?",
  tools: [getOrderStatusTool] // 🧰 On lui prête notre boîte à outils !
});`}
</CodeBlock>

### 7. Exécuter l'action et renvoyer la réponse

Votre serveur inspecte ce que Gemini a demandé et lui apporte la réponse :

<CodeBlock language="typescript">
{`// 1. Notre vraie fonction locale qui connaît la base de données
function getOrderStatusFromDatabase(orderId: number): string {
  const tableDesCommandes: Record<number, string> = {
    101: "Livrée hier à 14h",
    102: "En cours de préparation dans notre entrepôt de Lyon",
    103: "Annulée par le client"
  };
  return tableDesCommandes[orderId] || "Commande introuvable";
}

// 2. On regarde si Gemini a demandé un appel d'outil
const stepToolCall = interaction.steps.find((s) => s.type === "function_call");

if (stepToolCall && stepToolCall.type === "function_call") {
  const { name, arguments: args, id: callId } = stepToolCall;

  // On vérifie le nom de l'outil
  if (name === "get_order_status") {
    // On exécute notre fonction locale en toute sécurité
    const databaseResult = getOrderStatusFromDatabase((args as any).order_id);

    // On renvoie le résultat à Gemini pour qu'il formule la réponse finale
    const finalAnswer = await ai.interactions.create({
      model: GEMINI_MODEL,
      previous_interaction_id: interaction.id,
      input: [
        {
          type: "function_result",
          name,
          call_id: callId,
          result: databaseResult
        }
      ]
    });

    console.log("Réponse finale au client :", finalAnswer.output_text);
    // Résultat : "Votre commande 102 est actuellement en cours de préparation dans notre entrepôt de Lyon."
  }
}`}
</CodeBlock>
