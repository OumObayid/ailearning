# Évaluation des acquis du Module 1

### 1. Évaluation théorique

L'apprenant doit être capable d'expliquer :
1. Qu'est-ce qu'un LLM ?
2. Qu'est-ce qu'un token ?
3. Qu'est-ce que la fenêtre de contexte ?
4. Qu'est-ce qu'une hallucination ?
5. Quel est le rôle du SDK `@google/genai` ?
6. Qu'est-ce que l'Interactions API ?
7. Quelle différence existe entre une requête et une conversation ?
8. Quel est le rôle de `previous_interaction_id` ?
9. Pourquoi utiliser une sortie structurée ?
10. Pourquoi valider les réponses avec Zod ?
11. Quelle différence existe entre streaming et génération classique ?
12. Quelle différence existe entre Structured Output et Function Calling ?
13. Pourquoi le Function Calling nécessite-t-il une exécution côté application ?
14. Comment protéger une clé API ?
15. Comment gérer les quotas et les erreurs ?

---

### 2. Évaluation pratique

Réaliser les exercices suivants sans recopier intégralement les exemples du cours :
- **Exercice 1 :** Créer une API de génération de texte.
- **Exercice 2 :** Développer un analyseur de données libres.
- **Exercice 3 :** Extraire des informations dans un JSON validé par Zod.
- **Exercice 4 :** Construire une conversation avec plusieurs interactions.
- **Exercice 5 :** Transmettre progressivement une réponse avec SSE.
- **Exercice 6 :** Développer un assistant utilisant une fonction externe.
- **Exercice 7 :** Réaliser un audit des erreurs et de la sécurité.
