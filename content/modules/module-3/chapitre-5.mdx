# Chapitre 5 — Responsabilités des couches logicielles

### 1. Découpage en couches architecturales

Dans un projet backend industriel, mélanger la logique HTTP, la validation des paramètres, les requêtes SQL et les appels d'API dans un fichier unique conduit inévitablement à un code fragile et difficilement maintenable (*code spaghetti*).

L'architecture en couches sépare rigoureusement les préoccupations logicielles :

| Couche logicielle | Emplacement | Responsabilité exclusive | Ce qu'elle ne doit JAMAIS faire |
| :--- | :--- | :--- | :--- |
| **Routes** | `src/routes/` | Associe une méthode HTTP et une URL aux middlewares et au contrôleur | Exécuter des calculs ou appeler des APIs externes |
| **Middlewares** | `src/middlewares/` | Intercepte la requête pour valider, authentifier ou tracer | Renvoyer la réponse finale sauf en cas d'erreur ou de rejet |
| **Contrôleurs** | `src/controllers/` | Récupère les données validées, orchestre les services et forme la réponse HTTP | Contenir des requêtes SQL ou du code de SDK externe |
| **Services** | `src/services/` | Héberge la logique métier pure, interroge Gemini et MySQL | Manipuler les objets HTTP `req` et `res` d'Express |

### 2. Exemple concret de séparation nette

#### Le contrôleur reste purement axé sur le protocole HTTP :

```typescript
// src/controllers/ai.controller.ts
export const classifyTextController: RequestHandler = async (req, res, next) => {
  try {
    const { text, categories } = req.body;
    // Appel du service sans connaissance des objets Express
    const classification = await classifyWithGemini(text, categories);

    res.status(200).json({
      success: true,
      category: classification,
    });
  } catch (error) {
    next(error);
  }
};
```

#### Le service reste totalement indépendant du protocole HTTP :

```typescript
// src/services/classification.service.ts
export async function classifyWithGemini(text: string, categories: string[]): Promise<string> {
  // Logique purement métier et IA, testable unitairement sans serveur web
  const interaction = await ai.interactions.create({
    model: DEFAULT_GEMINI_MODEL,
    input: `Classe ce texte dans l'une des catégories suivantes [${categories.join(', ')}] :\n${text}`,
  });
  return interaction.outputs?.[0]?.text?.trim() || 'Inconnu';
}
```
