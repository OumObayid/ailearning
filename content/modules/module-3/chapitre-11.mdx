# Chapitre 11 — Observabilité, streaming et communication avec React

### 1. Pourquoi l'observabilité est-elle capitale dans un backend IA ?

Dans une architecture web classique, une requête qui ralentit signale généralement une requête SQL non indexée.

Dans une API d'intelligence artificielle, un ralentissement peut être dû à :
- La congestion temporaire des serveurs de Google Cloud.
- Un prompt utilisateur excessivement verbeux déclenchant une génération de plusieurs milliers de tokens.
- Un goulet d'étranglement lors de l'insertion concurrente en base de données MySQL.

Pour isoler la cause exacte, le backend doit mesurer et tracer séparément **chaque segment de durée** de la requête.

### 2. Middleware de journalisation structurée

Voici comment implémenter un middleware mesurant la durée d'exécution sans journaliser de secrets :

```typescript
// src/middlewares/logger.middleware.ts
import type { RequestHandler } from 'express';

export const requestLogger: RequestHandler = (req, res, next) => {
  const start = performance.now();

  res.on('finish', () => {
    const duration = (performance.now() - start).toFixed(1);
    const logData = {
      timestamp: new Date().toISOString(),
      method: req.method,
      url: req.originalUrl,
      statusCode: res.statusCode,
      durationMs: `${duration}ms`,
      ip: req.ip,
    };

    console.log(`[HTTP] ${logData.method} ${logData.url} ${logData.statusCode} — ${logData.durationMs}`);
  });

  next();
};
```

<Callout type="note" title="Bonne pratique de journalisation">
N'enregistrez jamais le contenu brut des prompts dans des fichiers de logs non chiffrés. Ils peuvent contenir des données personnelles confidentielles (noms, e-mails, chiffres) soumises à la réglementation sur la protection de la vie privée (RGPD).
</Callout>

### 3. Gérer les timeouts sur les appels longs

Pour éviter qu'une requête ne reste bloquée indéfiniment en cas d'indisponibilité du fournisseur IA, définissez toujours un **délai d'expiration strict** (*timeout*) :

```typescript
// src/services/gemini-timeout.service.ts
export async function generateWithTimeout(prompt: string, timeoutMs: number = 15000): Promise<string> {
  const timeoutPromise = new Promise<never>((_, reject) =>
    setTimeout(() => reject(new Error('Délai d’attente dépassé auprès de Google Gemini (Timeout 15s)')), timeoutMs)
  );

  // Course entre la réponse de Gemini et le compte à rebours
  return Promise.race([
    generateWithGemini(prompt),
    timeoutPromise,
  ]);
}
```

### 4. Consommer l'API depuis un client React

Dans votre application frontend React, la communication s'effectue via un service typé :

```typescript
// frontend/src/services/ai.service.ts
const BACKEND_URL = 'http://localhost:3000/api';

export interface GenerationResult {
  success: boolean;
  result: string;
  conversationId?: number;
}

export async function askAssistant(prompt: string): Promise<string> {
  const response = await fetch(`${BACKEND_URL}/ai/generate`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ prompt }),
  });

  const data: GenerationResult = await response.json();

  if (!response.ok) {
    throw new Error(data.result || 'Erreur lors de la génération.');
  }

  return data.result;
}
```

#### Middleware de journalisation télémétrique prêt à l'emploi :
```typescript
// src/middlewares/logger.middleware.ts
import type { RequestHandler } from 'express';

export const requestLogger: RequestHandler = (req, res, next) => {
  const start = Date.now();

  res.on('finish', () => {
    const duration = Date.now() - start;
    const color = res.statusCode >= 400 ? '❌' : '✅';
    console.log(
      `${color} [${new Date().toISOString()}] ${req.method} ${req.originalUrl} — HTTP ${res.statusCode} (${duration}ms)`
    );
  });

  next();
};
```
