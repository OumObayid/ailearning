# Chapitre 11 — Construire l'API REST RAG avec Express

### 1. Spécification des points d'accès RAG

Pour proposer un service documentaire complet à nos applications clientes, l'API Express expose les routes suivantes :

```text
POST   /api/documents/upload   --> Téléversement et indexation automatique d'un PDF
GET    /api/documents          --> Liste des documents et statuts d'indexation
DELETE /api/documents/:id      --> Suppression synchronisée MySQL et Qdrant
POST   /api/rag/ask            --> Question-réponse sémantique avec citations
```

### 2. Schéma de validation Zod de la question

Dans `src/schemas/rag.schema.ts` :

```typescript
// src/schemas/rag.schema.ts
import { z } from 'zod';

export const ragQuestionSchema = z.object({
  question: z
    .string({ required_error: 'La question est obligatoire.' })
    .trim()
    .min(3, 'La question doit contenir au minimum 3 caractères.')
    .max(2000, 'La question ne peut excéder 2000 caractères.'),
  limit: z
    .number()
    .int()
    .min(1)
    .max(10)
    .default(5),
});

export type RagQuestionInput = z.infer<typeof ragQuestionSchema>;
```

### 3. Service d'orchestration RAG complet

Dans `src/services/rag-orchestrator.service.ts`, nous assemblons les briques logicielles :

```typescript
// src/services/rag-orchestrator.service.ts
import { generateEmbedding } from './embedding.service.js';
import { searchSimilarChunks } from './qdrant.service.js';
import { getChunksByIds, type RetrievedChunk } from './document.service.js';
import { buildRAGContext } from './context.service.js';
import { generateRAGAnswer } from './rag-generation.service.js';

export interface RAGResponse {
  answer: string;
  sources: { id: number; title: string; score?: number }[];
}

export async function askRAG(
  question: string,
  userId: number,
  limit: number = 5
): Promise<RAGResponse> {
  // 1. Vectorisation de la question de l'utilisateur
  const queryVector = await generateEmbedding(question);

  // 2. Recherche des plus proches voisins dans Qdrant filtrée par utilisateur
  const searchResults = await searchSimilarChunks(queryVector, userId, limit);

  // Cas où aucun document pertinent n'atteint le seuil minimal
  if (searchResults.length === 0) {
    return {
      answer: "Désolé, je ne trouve aucune information correspondante dans vos documents.",
      sources: [],
    };
  }

  // 3. Extraction des identifiants de chunks
  const chunkIds = searchResults.map((r) => r.payload.chunkId);

  // 4. Récupération sécurisée du texte intégral dans MySQL
  const chunks: RetrievedChunk[] = await getChunksByIds(chunkIds, userId);

  // 5. Construction du contexte structuré
  const contextText = buildRAGContext(chunks);

  // 6. Génération de la réponse finale par Gemini
  const answer = await generateRAGAnswer(question, contextText);

  return {
    answer,
    sources: chunks.map((c) => ({ id: c.id, title: c.title })),
  };
}
```

### 4. Contrôleur et route Express

Dans `src/controllers/rag.controller.ts` :

```typescript
// src/controllers/rag.controller.ts
import type { RequestHandler } from 'express';
import { askRAG } from '../services/rag-orchestrator.service.js';

export const askRAGController: RequestHandler = async (req, res, next) => {
  try {
    const { question, limit } = req.body;

    // En environnement de production, l'ID utilisateur provient du jeton JWT
    const userId = (req as any).user?.id || 1;

    const result = await askRAG(question, userId, limit);

    res.status(200).json({
      success: true,
      data: result,
    });
  } catch (error) {
    next(error);
  }
};
```

Puis dans `src/routes/rag.routes.ts` :

```typescript
// src/routes/rag.routes.ts
import { Router } from 'express';
import { askRAGController } from '../controllers/rag.controller.js';
import { validateBody } from '../middlewares/validate.middleware.js';
import { ragQuestionSchema } from '../schemas/rag.schema.js';

const router = Router();

router.post('/ask', validateBody(ragQuestionSchema), askRAGController);

export default router;
```
