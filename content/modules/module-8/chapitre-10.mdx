# Chapitre 10 — Orchestration avancée avec LangGraph.js et Human-in-the-Loop

### 1. Modélisation de l'agent documentaire avec StateGraph

Pour les flux décisionnels complexes nécessitant plusieurs étapes de réflexion, nous structurons la logique de l'agent à l'aide de **LangGraph.js** autour d'un état partagé :

<CodeBlock
  language="typescript"
  title="src/modules/agents/graph/agentState.ts — Schéma d'état LangGraph"
  code={`import { Annotation } from '@langchain/langgraph';

export const PlatformAgentState = Annotation.Root({
  userPrompt: Annotation<string>(),
  userId: Annotation<number>(),
  category: Annotation<string>(),
  retrievedDocuments: Annotation<string[]>({
    reducer: (curr, update) => [...curr, ...update],
    default: () => [],
  }),
  pendingSensitiveAction: Annotation<Record<string, unknown> | null>({
    reducer: (_, update) => update,
    default: () => null,
  }),
  isApproved: Annotation<boolean | undefined>(),
  finalAnswer: Annotation<string>(),
});

export type PlatformAgentStateType = typeof PlatformAgentState.State;`}
/>

### 3. Suspension d'action critique par interrupt() et reprise par Command

Lorsqu'un collaborateur demande la suppression d'un contrat ou l'envoi d'une notification massive, le nœud d'approbation suspend l'exécution :

<CodeBlock
  language="typescript"
  title="src/modules/agents/graph/approvalNode.ts — Interruption contrôlée"
  code={`import { interrupt, Command } from '@langchain/langgraph';

export async function sensitiveApprovalNode(state: any) {
  if (state.pendingSensitiveAction) {
    console.log("[LangGraph HITL] Suspension immédiate du graphe pour approbation humaine.");

    // Suspend le thread et sauvegarde le checkpoint exact
    const decision = interrupt({
      message: "Cette opération nécessite la validation formelle d'un superviseur.",
      actionDetails: state.pendingSensitiveAction,
    });

    return { isApproved: Boolean(decision) };
  }

  return { isApproved: true };
}`}
/>

Dès que l'auditeur clique sur **[Valider l'opération]** dans l'interface React, le contrôleur Express reprend l'exécution sur le même `thread_id` :

<CodeBlock
  language="typescript"
  title="src/modules/agents/controllers/agentResume.controller.ts — Reprise par Command"
  code={`import { Command } from '@langchain/langgraph';
import { platformCompiledGraph } from '../graph/platformGraph';

export async function resumeAgentExecution(threadId: string, approved: boolean) {
  const config = { configurable: { thread_id: threadId } };

  // Reprise transparente du graphe
  const result = await platformCompiledGraph.invoke(
    new Command({ resume: approved }),
    config
  );

  return result;
}`}
/>
