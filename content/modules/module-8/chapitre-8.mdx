### 2. Filtrage vectoriel par permissions d'accès dans Qdrant

Pour empêcher qu'un employé ne voie les fragments de fiches de paie ou de contrats confidentiels d'autres départements, Qdrant applique un filtre de payload au moment de la recherche :

<CodeBlock
  language="typescript"
  title="src/modules/rag/ragSearch.service.ts — Recherche avec filtrage d'accès"
  code={`import { qdrantClient } from '../../config/qdrant';
import { ai, EMBEDDING_MODEL } from '../../config/gemini';

export async function searchAuthorizedChunks(query: string, userId: number, limit: number = 4) {
  // 1. Calcul de l'embedding de la question
  const embedRes = await ai.models.embedContent({
    model: EMBEDDING_MODEL,
    contents: [{ parts: [{ text: query }] }],
  });

  const queryVector = embedRes.embedding?.values;
  if (!queryVector) throw new Error("Échec d'embedding de la requête.");

  // 2. Recherche vectorielle avec filtre de sécurité étanche
  const matches = await qdrantClient.search('enterprise_knowledge', {
    vector: queryVector,
    limit,
    score_threshold: 0.72, // Seuil de pertinence minimal anti-bruit
    filter: {
      should: [
        { key: 'userId', match: { value: userId } },       // Ses propres documents
        { key: 'isPublic', match: { value: true } },       // Documentation générale d'entreprise
      ],
    },
  });

  return matches;
}`}
/>
