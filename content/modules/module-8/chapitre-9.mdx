# Chapitre 9 — Catalogue d'outils typés et boucle d'agent avec Tool Calling

### 1. Définition du catalogue d'outils de la plateforme

Notre plateforme dote son assistant d'un trousseau d'outils métier déclarés auprès de Google Gemini :

| Outil (*Tool Name*) | Description fonctionnelle | Paramètres attendus (Zod) |
| :--- | :--- | :--- |
| `search_documents` | Recherche sémantique dans les documents autorisés via Qdrant | `{ query: string, maxResults?: number }` |
| `get_document_metadata` | Consultation du statut, date d'indexation et auteur d'un fichier | `{ documentId: number }` |
| `generate_summary_report` | Préparation d'une synthèse au format Markdown structuré | `{ topic: string, documentIds: number[] }` |
| `trigger_n8n_workflow` | Déclenchement d'un workflow d'automatisation externe | `{ workflowName: string, payload: object }` |

### 3. Boucle décisionnelle itérative (Agent Loop) et limitation MAX_STEPS

Voici le moteur de boucle autonome qui gère la sélection dynamique, la validation des types avec Zod et l'exécution sécurisée :

<CodeBlock
  language="typescript"
  title="src/modules/agents/platformAgentLoop.ts — Boucle décisionnelle"
  code={`import { ai, DEFAULT_GEMINI_MODEL } from '../../config/gemini';
import { platformToolDefinitions } from './tools/platformTools';
import { executePlatformTool } from './tools/dispatcher';

const MAX_STEPS = 6;

export async function runPlatformAgent(userGoal: string, userId: number): Promise<string> {
  let steps = 0;

  // 1. Amorce de la discussion avec les outils
  let interaction = await ai.interactions.create({
    model: DEFAULT_GEMINI_MODEL,
    input: userGoal,
    tools: platformToolDefinitions,
  });

  while (steps < MAX_STEPS) {
    steps++;
    const outputs = interaction.outputs ?? [];
    const toolCalls = outputs.filter((o) => o.type === 'function_call');

    // Si aucun outil n'est demandé, Gemini formule sa réponse finale
    if (toolCalls.length === 0) {
      const textOutput = outputs.find((o) => o.type === 'text');
      return textOutput?.text || "Tâche accomplie.";
    }

    // 2. Exécution des outils demandés
    const toolResults = [];
    for (const call of toolCalls) {
      console.log(\`[Agent Step \${steps}] Exécution outil : \${call.name}\`);
      const result = await executePlatformTool(call.name, call.arguments, userId);

      toolResults.push({
        type: 'function_result' as const,
        name: call.name,
        call_id: call.id,
        result: JSON.stringify(result),
      });
    }

    // 3. Réinjection des résultats en conservant le fil conversationnel
    interaction = await ai.interactions.create({
      model: DEFAULT_GEMINI_MODEL,
      previous_interaction_id: interaction.id,
      input: toolResults,
    });
  }

  throw new Error("L'agent a atteint le nombre maximal d'itérations autorisées sans converger.");
}`}
/>
