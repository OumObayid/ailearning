# Chapitre 4 — Expérience utilisateur IA (UX/UI) : Rassurer et Guider

Quand vous cliquez sur un bouton dans une application web traditionnelle (par exemple *"Mettre dans le panier"*), la réponse arrive en moins de 100 millisecondes. C'est presque instantané.

Avec une intelligence artificielle, tout change !
- **La réflexion prend du temps** : selon la complexité de la demande, Gemini peut mettre entre 1 et 8 secondes pour formuler sa réponse.
- **La taille est imprévisible** : l'IA peut répondre en 2 lignes ou en 5 paragraphes détaillés.
- **Le résultat varie** : chaque génération apporte des nuances différentes.

Si l'écran reste figé sans rien dire pendant 5 secondes, l'utilisateur va paniquer, croire que votre site est en panne et fermer l'onglet !  
Dans ce chapitre, nous allons apprendre à concevoir une **expérience utilisateur (UX) rassurante, agréable et interactive**.

---

### 1. Les 4 règles d'or d'une interface IA réussie

1. ⏱️ **Ne laissez jamais l'utilisateur dans le noir** : dès le clic, montrez une animation ou un squelette visuel (*skeleton*) prouvant que le système est au travail.
2. 🛑 **Donnez le contrôle (Le bouton "Arrêter")** : si l'IA s'emballe et écrit un roman fleuve inutile, l'utilisateur doit pouvoir stopper la génération d'un clic.
3. 📋 **Facilitez la vie de l'utilisateur** : ajoutez un petit bouton pour copier le texte dans le presse-papier en un clic au lieu de devoir tout surligner à la souris.
4. 🔁 **Proposez de régénérer** : une IA peut avoir une inspiration moyenne au premier essai. Un simple bouton *"Essayer une autre réponse"* transforme une déception en satisfaction !

---

### 2. L'indicateur de chargement transparent

Évitez les fausses barres de chargement qui avancent à 95% puis se bloquent bêtement !  
Préférez un indicateur moderne avec des mots clairs qui expliquent ce qui se passe :

<CodeBlock language="tsx" filename="src/components/AI/LoadingIndicator.tsx">
{`import React from 'react';

interface LoadingProps {
  message?: string;
}

export const LoadingIndicator: React.FC<LoadingProps> = ({
  message = "Gemini analyse votre question et prépare sa réponse..."
}) => {
  return (
    <div className="flex items-center gap-3 rounded-2xl border border-indigo-100 bg-indigo-50/70 p-4 text-sm text-indigo-900 shadow-xs">
      {/* 3 petits points qui sautillent en rythme */}
      <div className="flex gap-1.5 items-center">
        <span className="h-2.5 w-2.5 rounded-full bg-indigo-600 animate-bounce [animation-delay:-0.3s]" />
        <span className="h-2.5 w-2.5 rounded-full bg-indigo-600 animate-bounce [animation-delay:-0.15s]" />
        <span className="h-2.5 w-2.5 rounded-full bg-indigo-600 animate-bounce" />
      </div>
      <span className="font-medium">{message}</span>
    </div>
  );
};`}
</CodeBlock>

### 3. Le bouton "Arrêter" : Maîtriser `AbortController`

Avez-vous déjà voulu couper la parole poliment à quelqu'un qui parle trop longtemps ?  
En JavaScript, nous avons un outil standard formidable pour cela : **`AbortController`** !

C'est comme une télécommande d'arrêt d'urgence :
1. Quand on lance `fetch()`, on lui confie le signal d'arrêt (`signal: controller.signal`).
2. Si l'utilisateur clique sur le bouton rouge *"Arrêter"*, on appelle `controller.abort()`.
3. Le navigateur coupe immédiatement la connexion réseau avec le serveur, sans aucun gaspillage !

<CodeBlock language="typescript">
{`// 1. On prépare la télécommande d'arrêt
const controller = new AbortController();

try {
  const res = await fetch('/api/generate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt: "Écris une histoire sans fin..." }),
    // On relie le signal à notre requête :
    signal: controller.signal
  });

  const data = await res.json();
} catch (err: any) {
  if (err.name === 'AbortError') {
    console.log("L'utilisateur a interrompu la génération.");
  } else {
    console.error("Autre erreur :", err);
  }
}

// 2. Si l'utilisateur clique sur le bouton "Arrêter" :
function onUserClickStop() {
  controller.abort(); // Coupure nette et immédiate !
}`}
</CodeBlock>

### 5. Les boutons d'action indispensables (Copier, Régénérer, Avis)

Une fois que l'IA a rédigé une belle réponse, offrez une expérience 5 étoiles à vos utilisateurs grâce à une petite barre d'outils discrète :

<CodeBlock language="tsx" filename="src/components/AI/MessageActions.tsx">
{`import React, { useState } from 'react';

interface ActionsProps {
  content: string;
  onRegenerate: () => void;
}

export const MessageActions: React.FC<ActionsProps> = ({ content, onRegenerate }) => {
  const [copied, setCopied] = useState(false);
  const [feedback, setFeedback] = useState<'up' | 'down' | null>(null);

  // Copie automatique dans le presse-papier
  const handleCopy = async () => {
    await navigator.clipboard.writeText(content);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000); // Remet le bouton à l'état normal après 2 secondes
  };

  return (
    <div className="flex items-center gap-2 mt-2 pt-2 border-t border-slate-100 text-xs text-slate-500">
      {/* Bouton Copier */}
      <button
        onClick={handleCopy}
        className="flex items-center gap-1 px-2.5 py-1 rounded-lg hover:bg-slate-100 transition font-medium text-slate-600"
      >
        {copied ? '✅ Copié !' : '📋 Copier'}
      </button>

      {/* Bouton Régénérer */}
      <button
        onClick={onRegenerate}
        className="flex items-center gap-1 px-2.5 py-1 rounded-lg hover:bg-slate-100 transition font-medium text-slate-600"
      >
        🔄 Réessayer
      </button>

      <div className="ml-auto flex items-center gap-1">
        {/* Pouce haut */}
        <button
          onClick={() => setFeedback('up')}
          className={\`p-1.5 rounded-md hover:bg-slate-100 \${feedback === 'up' ? 'text-emerald-600 font-bold' : ''}\`}
          title="Réponse utile"
        >
          👍
        </button>
        {/* Pouce bas */}
        <button
          onClick={() => setFeedback('down')}
          className={\`p-1.5 rounded-md hover:bg-slate-100 \${feedback === 'down' ? 'text-rose-600 font-bold' : ''}\`}
          title="Réponse imprécise"
        >
          👎
        </button>
      </div>
    </div>
  );
};`}
</CodeBlock>
