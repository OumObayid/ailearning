# Chapitre 4 — Expérience utilisateur IA (UX/UI)

### 1. Pourquoi l'expérience utilisateur est-elle différente avec l'IA ?

Dans une application traditionnelle, une action de l'utilisateur (comme enregistrer un formulaire ou cliquer sur un filtre) produit un résultat déterministe et quasi instantané (généralement inférieur à 200 ms).

Dans une application enrichie par un modèle de langage (LLM) :
- **La latence est variable** : La réponse peut nécessiter entre 1 et 10 secondes selon la longueur du prompt et la charge de travail du modèle.
- **Le résultat est non-déterministe** : La formulation varie à chaque génération.
- **La longueur est imprévisible** : Le modèle peut produire deux phrases comme plusieurs paragraphes.
- **Le risque d'imprécision existe** : L'utilisateur doit pouvoir relire, corriger et valider le contenu avant son utilisation finale.

L'interface doit accompagner cette dynamique sans frustrer l'utilisateur.

---

### 2. La machine à états d'une interface IA

Une interface IA professionnelle doit implémenter une machine à états exhaustive :

| État | Comportement de l'interface | Recommandation visuelle |
| :--- | :--- | :--- |
| **Idle** | En attente d'une consigne | Formulaire net, suggestions d'exemples de prompts cliquables |
| **Loading** | Préparation de la requête | Indicateur de traitement discret, saisie verrouillée |
| **Streaming** | Réception progressive des tokens | Curseur clignotant, texte apparaissant mot à mot, bouton d'arrêt actif |
| **Success** | Génération terminée avec succès | Actions disponibles (copier, régénérer, insérer), formatage riche |
| **Error** | Incident réseau, quota ou sécurité | Message compréhensible, bouton d'essai avec conservation du prompt |
| **Cancelled** | Interruption demandée par l'utilisateur | Mention d'arrêt propre, possibilité de relancer une consigne |
| **Empty** | Réponse vide ou filtrée par sécurité | Explication pédagogue invitant à reformuler la demande |

### 3. Afficher un indicateur de chargement transparent

Il est recommandé d'utiliser des indicateurs honnêtes plutôt que des animations trompeuses :

```tsx
// src/components/AI/LoadingIndicator.tsx
import React from 'react';

export const LoadingIndicator: React.FC<{ stage?: string }> = ({ stage = "Gemini analyse votre demande..." }) => {
  return (
    <div className="flex items-center gap-3 rounded-xl border border-indigo-100 bg-indigo-50/60 p-4 text-sm text-indigo-900" role="status" aria-live="polite">
      <div className="flex gap-1">
        <span className="h-2 w-2 rounded-full bg-indigo-600 animate-bounce [animation-delay:-0.3s]" />
        <span className="h-2 w-2 rounded-full bg-indigo-600 animate-bounce [animation-delay:-0.15s]" />
        <span className="h-2 w-2 rounded-full bg-indigo-600 animate-bounce" />
      </div>
      <span className="font-medium">{stage}</span>
    </div>
  );
};
```

### 4. Afficher du Markdown en toute sécurité

Les LLM structurent naturellement leurs réponses avec des listes, des titres, des citations et des blocs de code au format Markdown.

Pour afficher ce contenu dans React sans risque d'injection XSS :

```bash
npm install react-markdown remark-gfm
```

```tsx
// src/components/AI/MarkdownResponse.tsx
import React from 'react';
import ReactMarkdown from 'react-markdown';
import remarkGfm from 'remark-gfm';

interface Props {
  content: string;
}

export const MarkdownResponse: React.FC<Props> = ({ content }) => {
  return (
    <div className="prose prose-slate max-w-none text-sm sm:text-base leading-relaxed text-slate-800">
      <ReactMarkdown
        remarkPlugins={[remarkGfm]}
        components={{
          // Rendu contrôlé des liens pour forcer l'ouverture sécurisée
          a: ({ href, children }) => (
            <a href={href} target="_blank" rel="noopener noreferrer" className="text-indigo-600 underline hover:text-indigo-800">
              {children}
            </a>
          ),
        }}
      >
        {content}
      </ReactMarkdown>
    </div>
  );
};
```

<Callout type="warning" title="Alerte Sécurité XSS">
N'utilisez jamais `dangerouslySetInnerHTML` pour restituer une réponse issue d'un modèle d'IA. Un prompt malveillant pourrait manipuler le modèle pour injecter des balises `<script>` malveillantes.
</Callout>

### 5. Actions contextuelles et accessibilité

Chaque bloc de réponse doit comporter une barre d'outils d'actions rapides :
- **Bouton Copier** : Place le contenu brut dans le presse-papier via l'API standard `navigator.clipboard.writeText()`.
- **Régénération** : Relance la requête avec les mêmes paramètres si la réponse est insatisfaisante.
- **Régions ARIA (`aria-live="polite"`)** : Informe les lecteurs d'écran dès qu'une nouvelle réponse commence à s'écrire.

#### Implémentation du composant Markdown sécurisé avec copie :
```tsx
import React, { useState } from 'react';
import ReactMarkdown from 'react-markdown';
import remarkGfm from 'remark-gfm';

interface MarkdownViewProps {
  content: string;
}

export const MarkdownView: React.FC<MarkdownViewProps> = ({ content }) => {
  const [copied, setCopied] = useState(false);

  const handleCopy = async () => {
    await navigator.clipboard.writeText(content);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };

  return (
    <div className="relative group">
      <div className="prose prose-slate max-w-none text-slate-800" aria-live="polite">
        <ReactMarkdown remarkPlugins={[remarkGfm]}>
          {content}
        </ReactMarkdown>
      </div>

      <button
        onClick={handleCopy}
        aria-label="Copier le texte"
        className="absolute top-0 right-0 p-1.5 text-sm bg-slate-100 hover:bg-slate-200 text-slate-600 rounded-lg opacity-0 group-hover:opacity-100 transition-opacity"
      >
        {copied ? '✅ Copié !' : '📋 Copier'}
      </button>
    </div>
  );
};
```
