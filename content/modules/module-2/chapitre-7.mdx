# Chapitre 7 — Sorties structurées et UI générative (Generative UI)

Jusqu'à maintenant, toutes les réponses que Gemini nous a renvoyées s'affichaient sous la forme de texte dans une bulle de discussion.  
C'est très utile pour lire un poème ou une explication, mais posez-vous cette question :  
Quand vous consultez la météo sur votre smartphone, préférez-vous lire un long paragraphe ou voir une jolie icône de soleil avec la température en gros caractères et un bouton cliquable ?

C'est exactement l'objectif de **l'UI générative** (*Generative UI*) !  
Dans ce chapitre, nous allons apprendre à faire produire à Gemini des données structurées que React transforme instantanément en de superbes **cartes interactives, graphiques et boutons d'action**.

---

### 1. Qu'est-ce que l'UI générative contrôlée ?

Une idée fausse très répandue chez les débutants est de croire que l'IA va "écrire du code React" en direct pour fabriquer un bouton.  
Ce serait extrêmement dangereux : si l'IA faisait une faute de syntaxe ou générait un script malveillant, votre site planterait immédiatement !

En ingénierie professionnelle, on utilise **l'UI générative contrôlée** :
1. **L'IA fournit la matière première** : elle extrait ou calcule des données sous forme de données JSON ultra-propres (validées par Zod).
2. **React fournit le costume sur mesure** : vous avez préalablement préparé de magnifiques composants React (carte météo, fiche produit, jauge de performance).
3. **Le mariage parfait** : dès que les données JSON arrivent, React les injecte dans le composant adapté pour l'afficher à l'écran !

---

### 2. Exemple comparatif : Texte brut vs Carte interactive

Regardez la différence :

#### ❌ Réponse en texte brut (difficile à lire)
> *"Le produit est le Clavier Sans Fil Pro. Il coûte 79 euros. Il est actuellement en stock avec 14 exemplaires disponibles. La note moyenne des clients est de 4,7 sur 5."*

#### ✅ UI Générative (immédiat, beau et cliquable)
React reçoit ce JSON :
```json
{
  "nom": "Clavier Sans Fil Pro",
  "prix": 79,
  "enStock": true,
  "quantite": 14,
  "note": 4.7
}
```
Et affiche instantanément cette carte graphique avec une photo, un badge vert *"En stock (14 restants)"*, des étoiles dorées et un bouton bleu *"Ajouter au panier"* !

### 4. Comment construire un composant d'UI générative ?

Prenons le cas d'un assistant de santé financière pour une boutique en ligne.

#### Étape 1 : Le composant React prêt à accueillir les données (`ScoreCard.tsx`)
<CodeBlock language="tsx" filename="src/components/ScoreCard.tsx">
{`import React from 'react';

export interface AuditData {
  score: number;         // Note sur 100
  titre: string;
  pointsForts: string[];
  alerte?: string;
}

export const ScoreCard: React.FC<{ data: AuditData }> = ({ data }) => {
  const isBon = data.score >= 70;

  return (
    <div className="rounded-2xl border border-slate-200 bg-white p-5 shadow-sm space-y-4 max-w-md">
      {/* En-tête avec note circulaire */}
      <div className="flex items-center justify-between">
        <h3 className="font-bold text-slate-900">{data.titre}</h3>
        <span className={\`text-lg font-black px-3 py-1 rounded-full \${
          isBon ? 'bg-emerald-100 text-emerald-800' : 'bg-amber-100 text-amber-800'
        }\`}>
          {data.score} / 100
        </span>
      </div>

      {/* Points forts */}
      <div>
        <span className="text-xs font-bold text-slate-400 uppercase tracking-wider">Points forts</span>
        <ul className="mt-1 space-y-1 text-sm text-slate-700">
          {data.pointsForts.map((pt, i) => (
            <li key={i} className="flex items-center gap-1.5">
              <span className="text-emerald-500 font-bold">✓</span> {pt}
            </li>
          ))}
        </ul>
      </div>

      {/* Alerte éventuelle */}
      {data.alerte && (
        <div className="p-3 bg-amber-50 border border-amber-200 rounded-xl text-xs text-amber-900">
          ⚠️ <strong>Attention :</strong> {data.alerte}
        </div>
      )}

      {/* Bouton d'action concrète */}
      <button className="w-full py-2 bg-indigo-600 text-white rounded-xl text-xs font-bold hover:bg-indigo-700 transition">
        Télécharger le rapport détaillé
      </button>
    </div>
  );
};`}
</CodeBlock>

#### Étape 2 : L'appel sécurisé côté serveur avec Zod
Côté serveur, nous demandons à Gemini de remplir exactement cette structure :

<CodeBlock language="typescript">
{`import { generateObject } from 'ai';
import { google } from '@ai-sdk/google';
import { z } from 'zod';

const AuditSchema = z.object({
  score: z.number().min(0).max(100),
  titre: z.string(),
  pointsForts: z.array(z.string()).min(1),
  alerte: z.string().optional()
});

export async function genererAudit(texteRapport: string) {
  const { object } = await generateObject({
    model: google('gemini-2.5-flash'),
    schema: AuditSchema,
    prompt: \`Analyse ce rapport d'activité et produis l'audit : \${texteRapport}\`,
  });

  return object; // Les données sont validées et prêtes pour React !
}`}
</CodeBlock>

Dès que React reçoit `object`, il lui suffit de faire `<ScoreCard data={object} />`, et la magie visuelle opère !
