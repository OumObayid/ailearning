# Chapitre 6 — Les Hooks Magiques : `useChat` et `useCompletion`

Au Chapitre 3, nous avions codé un chat complet à la main : gérer la liste des messages, écouter le champ de saisie, décoder le JSON, gérer les `try / catch` et les états de chargement... Cela demandait une cinquantaine de lignes de code attentives.

Et si tout cela pouvait être résumé en **une seule petite ligne de code** ?

C'est exactement ce que propose la bibliothèque `@ai-sdk/react` grâce à son hook vedette : **`useChat`** !  
Dans ce chapitre, nous allons découvrir comment ce hook révolutionne le développement d'interfaces IA en gérant le streaming, la mémoire et les formulaires automatiquement.

---

### 1. Pourquoi le hook `useChat` est-il une bénédiction pour les développeurs ?

Pensez à un pilote automatique dans un avion moderne :  
Vous n'avez plus besoin d'ajuster manuellement chaque micro-vanne de carburant ou gouvernail à chaque seconde ; le système s'occupe de la stabilité en tâche de fond, vous n'avez qu'à lui indiquer la destination.

`useChat` est ce **pilote automatique pour React** :
- Il gère pour vous la liste des messages (`messages`).
- Il gère pour vous le champ de texte (`input`) et ce que tape l'utilisateur (`handleInputChange`).
- Il gère la soumission du formulaire (`handleSubmit`) sans recharger la page.
- Il se branche automatiquement sur votre flux de streaming et fait apparaître les mots un par un !
- Il vous fournit même un voyant de chargement (`isLoading`) et un bouton d'arrêt d'urgence (`stop`) prêts à l'emploi !

### 4. Développer un Chat complet en 25 lignes de code !

Installez d'abord la bibliothèque côté frontend :
```bash
npm install @ai-sdk/react
```

Voici le composant complet dans `src/components/SmartChat.tsx` :

<CodeBlock language="tsx" filename="src/components/SmartChat.tsx">
{`import React from 'react';
import { useChat } from '@ai-sdk/react';

export default function SmartChat() {
  // 🪄 Un seul hook magique pour tout gérer !
  const {
    messages,            // La liste de tous les messages échangés
    input,               // Le texte actuellement tapé dans le champ
    handleInputChange,   // La fonction pour mettre à jour ce que l'utilisateur tape
    handleSubmit,        // La fonction qui envoie le message et déclenche le streaming
    isLoading,           // Vaut true pendant que l'IA rédige
    stop,                // Fonction pour interrompre l'IA en un clic
    reload               // Fonction pour régénérer la dernière réponse
  } = useChat({
    api: 'http://localhost:3000/api/ai/chat-stream', // L'adresse de notre route backend
  });

  return (
    <div className="max-w-2xl mx-auto p-4 space-y-4 font-sans">
      {/* Zone d'affichage des messages */}
      <div className="space-y-3 min-h-[350px] max-h-[500px] overflow-y-auto p-4 bg-slate-50 border border-slate-200 rounded-2xl">
        {messages.map((m) => (
          <div
            key={m.id}
            className={\`flex \${m.role === 'user' ? 'justify-end' : 'justify-start'}\`}
          >
            <div
              className={\`max-w-[80%] rounded-2xl p-3 text-sm \${
                m.role === 'user'
                  ? 'bg-indigo-600 text-white rounded-br-none'
                  : 'bg-white text-slate-800 border border-slate-200 rounded-bl-none shadow-xs'
              }\`}
            >
              <div className="text-[11px] font-bold opacity-70 mb-1">
                {m.role === 'user' ? 'Vous' : '🤖 Gemini'}
              </div>
              <p className="whitespace-pre-wrap">{m.content}</p>
            </div>
          </div>
        ))}

        {isLoading && (
          <div className="text-xs text-indigo-600 font-medium italic animate-pulse">
            Gemini est en train d'écrire...
          </div>
        )}
      </div>

      {/* Formulaire d'envoi */}
      <form onSubmit={handleSubmit} className="flex gap-2">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Posez votre question à Gemini..."
          className="flex-1 p-3 border border-slate-300 rounded-xl text-sm focus:border-indigo-500 focus:outline-none"
        />

        {isLoading ? (
          <button
            type="button"
            onClick={stop}
            className="px-5 py-2.5 bg-rose-600 text-white text-sm font-bold rounded-xl hover:bg-rose-700 transition"
          >
            Arrêter
          </button>
        ) : (
          <button
            type="submit"
            disabled={!input.trim()}
            className="px-5 py-2.5 bg-indigo-600 text-white text-sm font-bold rounded-xl hover:bg-indigo-700 disabled:opacity-50 transition"
          >
            Envoyer
          </button>
        )}
      </form>
    </div>
  );
}`}
</CodeBlock>

Regardez la simplicité : vous n'avez écrit aucun `useState`, aucun `fetch()`, aucun décodeur de texte ! Tout est pris en charge par `useChat`.

### 5. Pour les questions ponctuelles : Le hook `useCompletion`

Si votre application ne fait pas de conversation de type chat, mais remplit simplement un champ de texte (par exemple : rédiger la biographie d'un utilisateur ou corriger l'orthographe d'un e-mail), Vercel propose un hook encore plus simple : **`useCompletion`**.

<CodeBlock language="tsx">
{`import { useCompletion } from '@ai-sdk/react';

export function BioAssistant() {
  const { completion, input, handleInputChange, handleSubmit, isLoading } = useCompletion({
    api: 'http://localhost:3000/api/ai/completion',
  });

  return (
    <form onSubmit={handleSubmit} className="space-y-3">
      <input
        value={input}
        onChange={handleInputChange}
        placeholder="Donnez vos passions pour votre bio..."
        className="w-full p-2 border rounded-xl"
      />
      <button type="submit" disabled={isLoading} className="btn-primary">
        Générer ma biographie
      </button>

      {/* Le texte apparaît en streaming ici au fur et à mesure ! */}
      {completion && (
        <div className="p-4 bg-slate-100 rounded-xl text-sm">
          {completion}
        </div>
      )}
    </form>
  );
}`}
</CodeBlock>
