# Chapitre 8 — Multimodalité et interactions avancées

### 1. Qu'est-ce qu'une interface multimodale ?

Une interface multimodale permet à l'utilisateur de combiner différents médias au sein d'une même interaction avec l'intelligence artificielle :
- Du texte naturel.
- Des photographies et captures d'écran.
- Des documents administratifs ou techniques (PDF).
- Des fichiers audios et vidéos lorsque le modèle le permet.

Grâce aux capacités natives multimodales de **Google Gemini**, une application peut analyser simultanément une image et des consignes textuelles d'accompagnement.

---

### 2. Prévisualiser un fichier dans React

Lorsqu'un utilisateur sélectionne une image, l'interface doit la prévisualiser immédiatement pour lui permettre de vérifier son choix avant l'envoi :

```tsx
// src/components/Upload/ImageUpload.tsx
import React, { useState, useEffect } from 'react';

export const ImageUpload: React.FC<{ onFileSelect: (file: File) => void }> = ({ onFileSelect }) => {
  const [selectedFile, setSelectedFile] = useState<File | null>(null);
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;

    if (!file.type.startsWith('image/')) {
      alert('Veuillez sélectionner un format d’image valide (PNG, JPEG, WebP).');
      return;
    }

    if (file.size > 5 * 1024 * 1024) {
      alert('La taille de l’image ne doit pas dépasser 5 Mo.');
      return;
    }

    setSelectedFile(file);
    setPreviewUrl(URL.createObjectURL(file));
    onFileSelect(file);
  };

  // Libération mémoire de l'URL objet lors du démontage
  useEffect(() => {
    return () => {
      if (previewUrl) {
        URL.revokeObjectURL(previewUrl);
      }
    };
  }, [previewUrl]);

  return (
    <div className="space-y-4">
      <input
        type="file"
        accept="image/png, image/jpeg, image/webp"
        onChange={handleFileChange}
        className="block w-full text-sm text-slate-500 file:mr-4 file:py-2.5 file:px-4 file:rounded-xl file:border-0 file:text-sm file:font-semibold file:bg-indigo-50 file:text-indigo-700 hover:file:bg-indigo-100 cursor-pointer"
      />

      {previewUrl && (
        <div className="relative inline-block rounded-2xl overflow-hidden border border-slate-200 shadow-sm">
          <img src={previewUrl} alt="Aperçu du fichier" className="max-h-64 object-cover" />
          <span className="absolute bottom-2 left-2 rounded-md bg-slate-900/80 px-2.5 py-0.5 text-sm text-white">
            {(selectedFile!.size / 1024).toFixed(0)} Ko
          </span>
        </div>
      )}
    </div>
  );
};
```

### 3. Envoyer le fichier au backend avec FormData

Pour transmettre des fichiers binaires accompagnés d'instructions texte, nous utilisons l'objet standard `FormData` :

```typescript
// src/services/upload.service.ts
export async function analyzeImageWithPrompt(file: File, prompt: string) {
  const formData = new FormData();
  formData.append('image', file);
  formData.append('prompt', prompt);

  const response = await fetch('/api/analyze-image', {
    method: 'POST',
    // IMPORTANT : Ne JAMAIS spécifier 'Content-Type' manuellement ici !
    // Le navigateur doit injecter lui-même 'multipart/form-data' avec son 'boundary'.
    body: formData,
  });

  if (!response.ok) {
    throw new Error("Échec lors de l'analyse multimodale.");
  }

  return response.json();
}
```

<Callout type="note" title="Règle technique FormData">
Ne définissez jamais l'en-tête `Content-Type: multipart/form-data` manuellement dans vos requêtes `fetch`. Le navigateur doit obligatoirement calculer et adjoindre le paramètre `boundary` sous peine de rendre le corps de requête illisible pour le serveur.
</Callout>

---

### 4. Sécurité et validation des fichiers

Le contrôle de l'attribut HTML `accept="image/*"` est une simple commodité ergonomique côté client. Le serveur backend doit impérativement réitérer les vérifications suivantes :
1. **Contrôle du type MIME réel** via l'inspection des octets magiques (*magic bytes*) du fichier.
2. **Plafond de taille stricte** (ex. 5 ou 10 Mo maximum) pour éviter l'épuisement mémoire du serveur.
3. **Nettoyage du nom de fichier** pour neutraliser tout risque d'attaque par traversée de répertoire (*path traversal*).

#### Gestion de l'aperçu et du nettoyage mémoire en React :
```tsx
import React, { useState, useEffect } from 'react';

export const ImageDropzone: React.FC = () => {
  const [file, setFile] = useState<File | null>(null);
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);
  const [analysis, setAnalysis] = useState<string>('');
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (!file) {
      setPreviewUrl(null);
      return;
    }
    const objectUrl = URL.createObjectURL(file);
    setPreviewUrl(objectUrl);

    // Nettoyage impératif pour éviter les fuites de mémoire
    return () => URL.revokeObjectURL(objectUrl);
  }, [file]);

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const selected = e.target.files?.[0];
    if (selected) {
      if (selected.size > 5 * 1024 * 1024) {
        alert('Image trop volumineuse (limite : 5 Mo).');
        return;
      }
      setFile(selected);
    }
  };

  const handleUpload = async () => {
    if (!file) return;
    setLoading(true);

    const formData = new FormData();
    formData.append('image', file);
    formData.append('prompt', 'Décris les éléments principaux de cette image.');

    try {
      const res = await fetch('http://localhost:3000/api/analyze-image', {
        method: 'POST',
        body: formData,
      });
      const data = await res.json();
      setAnalysis(data.result);
    } catch (err) {
      alert('Erreur lors de l\'analyse');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="p-6 border rounded-2xl bg-white space-y-4">
      <input type="file" accept="image/*" onChange={handleFileChange} />
      {previewUrl && (
        <div className="relative w-48 h-48 border rounded-xl overflow-hidden">
          <img src={previewUrl} alt="Aperçu" className="w-full h-full object-cover" />
          <button
            onClick={() => setFile(null)}
            className="absolute top-2 right-2 bg-red-600 text-white rounded-full p-1 text-sm"
          >
            ✕
          </button>
        </div>
      )}
      <button
        onClick={handleUpload}
        disabled={!file || loading}
        className="px-5 py-2 bg-indigo-600 text-white rounded-xl font-bold disabled:opacity-50"
      >
        {loading ? 'Analyse en cours...' : 'Lancer l\'analyse visuelle'}
      </button>
      {analysis && (
        <div className="p-4 bg-slate-50 rounded-xl border mt-4">
          <h4 className="font-bold text-sm text-slate-800">Résultat Gemini :</h4>
          <p className="mt-1 text-slate-700 whitespace-pre-wrap">{analysis}</p>
        </div>
      )}
    </div>
  );
};
```
