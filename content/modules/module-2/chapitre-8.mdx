# Chapitre 8 — La Multimodalité Côté Frontend : Images et Fichiers

Au Module 1, nous avons découvert que Gemini possède des yeux : il est capable d'analyser une photographie aussi bien que du texte écrit.  
Mais comment permettre à un visiteur sur votre site web d'ajouter une photo facilement ?

Dans ce chapitre, nous allons concevoir une **zone de dépôt d'images (Drag & Drop)** avec React, afficher une **vignette de prévisualisation instantanée**, et envoyer le tout de façon propre et sécurisée vers notre serveur.

---

### 1. Pourquoi la prévisualisation est-elle indispensable ?

Imaginez que vous envoyiez une photo sur un site :
- Si rien ne s'affiche, vous doutez : *"Est-ce que le fichier a bien été sélectionné ? Est-ce la bonne photo ?"*.
- En affichant immédiatement une **vignette miniature**, l'utilisateur est rassuré. Il peut vérifier son image, voir son nom et sa taille, ou cliquer sur une petite croix rouge pour la retirer s'il s'est trompé.

---

### 2. Le secret de la prévisualisation rapide : `URL.createObjectURL`

Pour afficher une image locale dans une balise `<img />` avant même qu'elle ne soit envoyée sur Internet, le navigateur possède une fonction magique : **`URL.createObjectURL(file)`**.

Elle crée une fausse adresse temporaire interne pointant directement vers la mémoire vive de l'ordinateur.  
Attention à la règle d'hygiène : quand l'utilisateur change d'image ou quitte la page, on appelle `URL.revokeObjectURL()` pour libérer la mémoire vive !

<CodeBlock language="tsx" filename="src/components/Upload/ImagePreview.tsx">
{`import React, { useState, useEffect } from 'react';

export const ImagePreview: React.FC = () => {
  const [selectedFile, setSelectedFile] = useState<File | null>(null);
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);

  // Dès qu'un fichier est choisi, on fabrique son adresse de prévisualisation
  useEffect(() => {
    if (!selectedFile) {
      setPreviewUrl(null);
      return;
    }

    const objectUrl = URL.createObjectURL(selectedFile);
    setPreviewUrl(objectUrl);

    // Nettoyage de la mémoire quand l'image change
    return () => URL.revokeObjectURL(objectUrl);
  }, [selectedFile]);

  return (
    <div className="space-y-3">
      <input
        type="file"
        accept="image/png, image/jpeg, image/webp"
        onChange={(e) => setSelectedFile(e.target.files?.[0] || null)}
        className="block text-sm text-slate-500 file:mr-4 file:py-2 file:px-4 file:rounded-xl file:border-0 file:text-sm file:font-semibold file:bg-indigo-50 file:text-indigo-700 hover:file:bg-indigo-100"
      />

      {/* Affichage de la vignette miniature */}
      {previewUrl && (
        <div className="relative inline-block border rounded-xl overflow-hidden shadow-xs">
          <img src={previewUrl} alt="Aperçu" className="h-36 w-36 object-cover" />
          <button
            onClick={() => setSelectedFile(null)}
            className="absolute top-1 right-1 bg-black/60 text-white rounded-full p-1 text-xs hover:bg-black transition"
            title="Supprimer la photo"
          >
            ✕
          </button>
        </div>
      )}
    </div>
  );
};`}
</CodeBlock>

### 4. Comment convertir l'image pour l'envoyer à Gemini ?

Pour envoyer votre image dans une requête JSON classique, la méthode la plus simple consiste à la transformer en chaîne de texte **Base64** grâce à l'outil standard `FileReader` du navigateur :

<CodeBlock language="typescript">
{`/**
 * Transforme un fichier image en texte Base64
 */
export function fileToBase64(file: File): Promise<string> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.readAsDataURL(file);

    reader.onload = () => {
      // Le résultat ressemble à : "data:image/jpeg;base64,/9j/4AAQSkZJRg..."
      // On retire l'en-tête pour ne garder que les données pures si besoin :
      const base64String = (reader.result as string).split(',')[1];
      resolve(base64String);
    };

    reader.onerror = (error) => reject(error);
  });
}`}
</CodeBlock>

Il vous suffit ensuite d'envoyer votre question et votre chaîne Base64 dans le corps de votre requête :
```typescript
const imageBase64 = await fileToBase64(selectedFile);

await fetch('/api/vision', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    prompt: "Que contient cette photo ?",
    imageBase64,
    mimeType: selectedFile.type
  })
});
```

### 5. Les contrôles de sécurité indispensables sur le frontend

Avant même d'appeler le serveur, votre composant React doit faire ces deux vérifications pour protéger l'utilisateur :
1. **La taille maximale** : Si le fichier dépasse 5 Mo, affichez immédiatement une alerte *"Votre image est trop lourde (maximum 5 Mo)"*. Cela évite de ralentir le navigateur et d'engorger la bande passante.
2. **Le format autorisé** : Vérifiez que `file.type` commence bien par `image/` (refusez les fichiers `.exe`, `.zip` ou inconnus).
