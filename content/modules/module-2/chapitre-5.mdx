# Chapitre 5 — Vercel AI SDK avec Google Gemini

Jusqu'à maintenant, nous avons écrit tout le code réseau à la main avec `fetch()` et le SDK officiel de Google.  
C'est un excellent exercice pour comprendre la mécanique sous le capot.

Mais dans les entreprises modernes, les développeurs utilisent souvent un accélérateur incroyable créé par l'équipe de Next.js : **Vercel AI SDK**.

Ne soyez pas intimidé par le mot *Vercel* : cette bibliothèque est entièrement gratuite, open source, et fonctionne à merveille avec **Google Gemini**, que vous utilisiez Express, Node.js ou Next.js !  
Dans ce chapitre, nous allons découvrir comment cet outil nous évite d'écrire des dizaines de lignes de code complexes pour le streaming et la validation de données.

---

### 1. Pourquoi utiliser Vercel AI SDK ?

Imaginez que vous deviez brancher votre smartphone sur différents types de prises à travers le monde :
- Sans adaptateur, vous devez racheter un chargeur spécifique pour chaque pays.
- Avec un adaptateur universel, vous gardez le même câble partout !

**Vercel AI SDK** est cet **adaptateur universel** pour l'intelligence artificielle :
- Il propose une syntaxe standardisée pour interroger Gemini, OpenAI, Claude ou Mistral.
- Il transforme le streaming temps réel (mot par mot) en un jeu d'enfant.
- Il s'intègre directement avec **Zod** pour garantir des données sans fautes.
- Il fournit des hooks React tout prêts (`useChat`) qui gèrent l'historique et la saisie pour vous !

---

### 2. Comparaison : SDK officiel de Google vs Vercel AI SDK

| Fonctionnalité | SDK Officiel (`@google/genai`) | Vercel AI SDK (`ai` + `@ai-sdk/google`) |
| :--- | :--- | :--- |
| **Philosophie** | Contrôle très précis des options exclusives de Google | Syntaxe universelle et standardisée |
| **Streaming UI** | Décodage manuel des flux SSE en Node.js | Une seule méthode : `toDataStreamResponse()` |
| **Intégration React** | Vous codez les `useState` et les `fetch` vous-même | Fournit des hooks magiques tout prêts (`useChat`) |
| **Validation JSON** | Vous devez lier Zod manuellement avec `.safeParse()` | Intégré nativement dans `generateObject()` |

Les deux approches sont très utilisées. Dans ce chapitre et le suivant, nous explorons Vercel AI SDK car il est devenu le standard incontournable pour les développeurs frontend React.

### 4. Installation des outils nécessaires

Dans votre projet backend (le serveur Node.js), installez les deux bibliothèques officielles :

```bash
npm install ai @ai-sdk/google zod
```

Assurez-vous que votre clé API est bien présente dans votre fichier `.env` :
```bash
GOOGLE_GENERATIVE_AI_API_KEY=VOTRE_CLE_API_GEMINI
```
*(Vercel AI SDK détecte automatiquement cette variable d'environnement sans configuration complexe).*

---

### 5. Les deux fonctions stars côté serveur

Vercel AI SDK repose sur deux fonctions principales extrêmement simples à mémoriser :

#### A. `generateText` : Pour une réponse ponctuelle en un seul bloc
<CodeBlock language="typescript">
{`import { generateText } from 'ai';
import { google } from '@ai-sdk/google';

// Demande simple et directe
const { text } = await generateText({
  model: google('gemini-2.5-flash'),
  prompt: 'Donne-moi trois conseils pour réussir une recette de crêpes.',
});

console.log(text);`}
</CodeBlock>

#### B. `streamText` : Pour diffuser la réponse en direct mot par mot
C'est la méthode reine pour vos interfaces de discussion. Elle s'associe directement avec une route Express ou Next.js :

<CodeBlock language="typescript" filename="src/controllers/chat.controller.ts">
{`import { streamText } from 'ai';
import { google } from '@ai-sdk/google';
import type { Request, Response } from 'express';

export async function chatStreamController(req: Request, res: Response) {
  const { messages } = req.body;

  // 1. On lance le streaming avec Google Gemini
  const result = streamText({
    model: google('gemini-2.5-flash'),
    messages, // L'historique complet des messages
  });

  // 2. Vercel AI SDK se charge de tout le protocole SSE vers le client en une ligne !
  result.pipeDataStreamToResponse(res);
}`}
</CodeBlock>

Fini les boucles infinies de décodage manuel d'octets : `pipeDataStreamToResponse` gère les en-têtes réseau, le découpage des morceaux et la fermeture de la connexion automatiquement !

### 6. Extraire des données typées avec `generateObject`

Si vous voulez forcer Gemini à vous renvoyer un objet JSON garanti par un schéma Zod, c'est encore plus simple :

<CodeBlock language="typescript">
{`import { generateObject } from 'ai';
import { google } from '@ai-sdk/google';
import { z } from 'zod';

// On définit le moule avec Zod
const RecetteSchema = z.object({
  titre: z.string(),
  tempsPreparationMinutes: z.number(),
  ingredients: z.array(z.string()),
  difficulte: z.enum(['FACILE', 'MOYEN', 'DIFFICILE'])
});

const { object } = await generateObject({
  model: google('gemini-2.5-flash'),
  schema: RecetteSchema,
  prompt: 'Propose une recette rapide pour le dîner.',
});

// object est déjà un objet JavaScript vérifié à 100% !
console.log(object.titre);
console.log(object.difficulte);`}
</CodeBlock>
