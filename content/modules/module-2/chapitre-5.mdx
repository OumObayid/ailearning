# Chapitre 5 — Vercel AI SDK avec Google Gemini

### 1. Qu'est-ce que Vercel AI SDK ?

**Vercel AI SDK** est une bibliothèque open source TypeScript majeure conçue pour standardiser le développement d'applications d'intelligence artificielle.

Elle apporte un ensemble unifié d'abstractions pour :
- La génération de texte simple (`generateText`).
- Le streaming de fragments en temps réel (`streamText`).
- La génération d'objets fortement typés validés par Zod (`generateObject`).
- Les hooks React orientés interface utilisateur (`useChat`, `useCompletion`).
- L'orchestration d'outils et le Function Calling unifié.

Dans notre cursus, nous utilisons Vercel AI SDK couplé au fournisseur officiel **Google Gemini** via `@ai-sdk/google`.

---

### 2. Comparatif : SDK Officiel Google versus Vercel AI SDK

| Critère | SDK Officiel (`@google/genai`) | Vercel AI SDK (`ai` + `@ai-sdk/google`) |
| :--- | :--- | :--- |
| **Philosophie** | Contrôle total des APIs spécifiques de Google | Abstraction unifiée agnostique du fournisseur |
| **Gestion d'état** | `Interactions API` avec gestion serveur native | Protocoles standardisés de streaming UI |
| **Intégration Frontend** | Code personnalisé côté React | Hooks React prêts à l'emploi (`useChat`) |
| **Streaming UI** | Décodage manuel des flux SSE | Adaptateur direct `pipeUIMessageStreamToResponse` |
| **Portabilité** | Écosystème Google exclusif | Remplacement facile du modèle par simple configuration |

---

### 3. Installation des dépendances

Installez les packages nécessaires dans votre projet backend Node.js :

```bash
npm install ai @ai-sdk/google zod
```

- `ai` : Cœur du SDK contenant les fonctions universelles (`generateText`, `streamText`, `generateObject`).
- `@ai-sdk/google` : Adaptateur officiel reliant Vercel AI SDK aux modèles Google Gemini.
- `zod` : Bibliothèque de déclaration de schémas et de validation de types.

---

### 4. Configurer le fournisseur Google Gemini

Dans votre serveur backend Node.js (ex. `src/services/gemini-provider.ts`) :

```typescript
// src/services/gemini-provider.ts
import { createGoogleGenerativeAI } from '@ai-sdk/google';

export const google = createGoogleGenerativeAI({
  apiKey: process.env.GEMINI_API_KEY,
});

// Sélection du modèle de travail Google Gemini
export const geminiModel = google('gemini-2.5-flash');
```

<Callout type="note" title="AI SDK direct vs AI Gateway">
Cette configuration se connecte **directement** à l'infrastructure Google Gemini sans intermédiaire. Ne confondez pas Vercel AI SDK avec des services de passerelle tiers payants (AI Gateway).
</Callout>

---

### 5. Génération synchrone avec generateText

Pour des opérations courtes d'analyse ou de transformation :

```typescript
import { generateText } from 'ai';
import { geminiModel } from './gemini-provider.js';

export async function explainConcept(concept: string) {
  const { text, usage } = await generateText({
    model: geminiModel,
    prompt: `Explique le concept suivant à un développeur junior : ${concept}`,
    system: "Tu es un tuteur technique expert, concis et pédagogue.",
  });

  console.log(`Tokens consommés : ${usage.totalTokens}`);
  return text;
}
```

---

### 6. Streaming de texte avec streamText

Pour les réponses longues, `streamText` délivre les fragments textuels au fur et à mesure de leur création par Gemini :

```typescript
import { streamText } from 'ai';
import { geminiModel } from './gemini-provider.js';

export async function streamExplanation(prompt: string) {
  const result = streamText({
    model: geminiModel,
    prompt,
  });

  // Consommation en direct des morceaux (chunks)
  for await (const chunk of result.textStream) {
    process.stdout.write(chunk);
  }
}
```

#### Script d'exemple complet pour le streaming console :
```typescript
// src/scripts/test-stream.ts
import 'dotenv/config';
import { streamText } from 'ai';
import { createGoogleGenerativeAI } from '@ai-sdk/google';

const google = createGoogleGenerativeAI({
  apiKey: process.env.GEMINI_API_KEY,
});

async function main() {
  console.log('--- Début du streaming Vercel AI SDK ---');

  const result = streamText({
    model: google('gemini-2.5-flash'),
    prompt: 'Explique la différence entre SSR et SPA en trois paragraphes percutants.',
  });

  for await (const chunk of result.textStream) {
    process.stdout.write(chunk);
  }

  const usage = await result.usage;
  console.log('\n\n--- Statistiques de consommation ---');
  console.log(`Tokens prompt : ${usage.promptTokens}`);
  console.log(`Tokens complétion : ${usage.completionTokens}`);
}

main().catch(console.error);
```
