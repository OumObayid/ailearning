# Chapitre 1 — Fondamentaux des applications frontend IA

### 1. Qu'est-ce qu'un frontend augmenté par l'IA ?

Un frontend augmenté par l'intelligence artificielle est une interface utilisateur qui intègre des fonctionnalités intelligentes capables d'interpréter des demandes en langage naturel, de générer du contenu contextualisé, d'analyser des données complexes et d'assister activement l'utilisateur dans ses flux de travail.

Dans une application web classique, l'utilisateur est limité à des interactions préprogrammées :
- Saisir manuellement des données dans des formulaires rigides.
- Naviguer entre des pages statiques ou semi-dynamiques.
- Consulter des données tabulaires brutes.
- Déclencher des actions strictement déterministes.

Dans un **frontend augmenté par l'IA**, l'interface acquiert de nouvelles capacités cognitives :
- **Comprendre** une intention utilisateur formulée librement en langage naturel.
- **Générer** une réponse personnalisée et adaptée au contexte applicatif.
- **Analyser** en temps réel un contenu saisi ou un document téléversé.
- **Transformer** des données disparates en informations actionnables.
- **Afficher** progressivement une réponse via le streaming temps réel.
- **Présenter** des résultats sous forme de composants visuels riches (UI générative).

#### Exemple concret
Imaginons une application de gestion de catalogue e-commerce :
- Dans une application classique, le gestionnaire rédige manuellement chaque ligne de la description du produit.
- Dans une application augmentée par l'IA, il saisit simplement :
> « Génère une description commerciale pour une robe noire élégante destinée à une boutique de mode féminine haut de gamme. »

Gemini produit instantanément une proposition persuasive que l'utilisateur peut relire, peaufiner, copier ou enregistrer en un clic dans la base de données. L'intelligence artificielle devient ainsi une brique intégrée à l'expérience métier.

### 2. Les principales catégories d'interfaces IA

| Interface | Fonction principale |
| :--- | :--- |
| **Chat IA** | Dialogue conversationnel multi-tours avec mémoire de contexte |
| **Générateur de contenu** | Production assistée de textes, résumés et reformulations |
| **Analyseur de données** | Extraction d'enseignements clés à partir de données textuelles ou chiffrées |
| **Assistant de formulaire** | Pré-remplissage intelligent, complétion et validation contextuelle |
| **Interface multimodale** | Analyse conjointe d'images, de photographies et de documents PDF |
| **Assistant contextuel** | Aide proactive basée sur la page ou la ressource actuellement consultée |
| **Interface avec outils** | Déclenchement contrôlé de fonctions métier via Function Calling |
| **Interface de streaming** | Restitution fluide et progressive des tokens générés par le LLM |

### 4. Pourquoi ne pas appeler directement Gemini depuis React ?

Le code d'une application React est entièrement téléchargé et exécuté dans le moteur JavaScript du navigateur de l'utilisateur.

Si une clé d'API Gemini était intégrée directement dans le frontend :
1. **Exposition critique** : Elle serait immédiatement visible en clair dans le code source minifié ou dans l'onglet *Réseau* des outils de développement.
2. **Vol de crédits et quotas** : N'importe quel utilisateur ou robot pourrait extraire la clé et consommer vos quotas d'API à vos frais.
3. **Absence de contrôle métier** : Vous ne pourriez ni limiter le débit (rate limiting), ni modérer les prompts, ni enregistrer les interactions en base de données.

La seule architecture viable consiste à ce que React communique avec votre propre API backend, qui joue le rôle de passerelle sécurisée.

---

### 5. Les responsabilités du frontend IA

Le rôle du frontend ne se résume pas à afficher un simple bloc de texte brut. Il assure l'expérience utilisateur complète :
- La collecte propre des intentions utilisateur et la validation immédiate des formulaires.
- La gestion fine des états d'attente (indicateurs de progression, squelettes de chargement).
- La réception et l'affichage fluide des flux de streaming temps réel.
- La gestion transparente des erreurs réseau et des reprises sur incident.
- La possibilité d'interrompre une réponse longue grâce à l'annulation de requête (`AbortController`).
- Le rendu sécurisé du Markdown et la mise en forme de composants structurés (**UI générative**).

#### Gabarit TypeScript suggéré pour démarrer :
```tsx
import React, { useState } from 'react';

type InteractionStatus = 'idle' | 'loading' | 'success' | 'error';

export const PromptSimulator: React.FC = () => {
  const [prompt, setPrompt] = useState('');
  const [status, setStatus] = useState<InteractionStatus>('idle');
  const [errorMessage, setErrorMessage] = useState('');
  const [response, setResponse] = useState('');

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (!prompt.trim()) {
      setStatus('error');
      setErrorMessage('Veuillez saisir une question avant de lancer la génération.');
      return;
    }
    if (prompt.length > 500) {
      setStatus('error');
      setErrorMessage('La taille maximale autorisée est de 500 caractères.');
      return;
    }

    setStatus('loading');
    setErrorMessage('');

    // Simulation d'une latence d'inférence de 2 secondes
    setTimeout(() => {
      setStatus('success');
      setResponse("Voici une simulation de réponse rédigée par l'intelligence artificielle.");
    }, 2000);
  };

  return (
    <form onSubmit={handleSubmit} className="p-6 border rounded-2xl bg-white space-y-4 shadow-sm">
      <textarea
        value={prompt}
        onChange={(e) => setPrompt(e.target.value)}
        disabled={status === 'loading'}
        placeholder="Posez votre question à l'IA..."
        className="w-full p-3 border rounded-xl"
        rows={4}
      />
      <div className="flex justify-between items-center text-sm text-slate-500">
        <span>{prompt.length} / 500 caractères</span>
        <button
          type="submit"
          disabled={status === 'loading' || !prompt.trim()}
          className="px-5 py-2.5 bg-indigo-600 text-white rounded-xl font-bold disabled:opacity-50"
        >
          {status === 'loading' ? 'Génération...' : 'Envoyer'}
        </button>
      </div>
      {status === 'error' && (
        <div className="p-3 bg-red-50 text-red-700 rounded-xl border border-red-200">
          ⚠️ {errorMessage}
        </div>
      )}
      {status === 'success' && (
        <div className="p-4 bg-emerald-50 text-emerald-900 rounded-xl border border-emerald-200">
          <strong>Réponse IA :</strong>
          <p className="mt-1">{response}</p>
        </div>
      )}
    </form>
  );
};
```
