# Chapitre 1 — Fondamentaux des applications frontend IA

Bienvenue dans le **Module 2** ! Dans le module précédent, nous avons appris à faire dialoguer un serveur avec Gemini en coulisses.  
Désormais, nous passons du côté visible de la scène : **le Frontend**, c'est-à-dire l'écran avec lequel vos utilisateurs interagissent tous les jours dans leur navigateur (avec React et TypeScript).

Construire une interface pour une intelligence artificielle n'a rien à voir avec un site web classique.  
Dans ce premier chapitre, nous allons comprendre pourquoi l'expérience utilisateur change complètement, et comment concevoir une application moderne, rassurante et fluide.

---

### 1. Qu'est-ce qu'un frontend "augmenté par l'IA" ?

Pour bien comprendre, faisons une comparaison simple :

- **Une application classique (le distributeur automatique) :**  
  Pensez à une machine à café à boutons. Vous appuyez sur *"Expresso sans sucre"*, la machine s'exécute de façon rigide. Si vous lui dites : *"J'ai eu une journée épuisante, prépare-moi une boisson réconfortante pas trop amère"*, la machine ne comprend absolument rien !
- **Une application augmentée par l'IA (le serveur attentif au comptoir) :**  
  L'utilisateur peut s'exprimer librement avec ses propres mots, en français de tous les jours. L'interface comprend son intention, l'aide à reformuler, lui génère du texte ou des visuels adaptés à sa situation, et lui affiche la réponse progressivement sous ses yeux.

#### Exemple concret dans un magasin en ligne
- **Site classique :** Le commerçant doit remplir 15 cases manuelles : titre, matière, coupe, saison, texte publicitaire...
- **Site augmenté par l'IA :** Le commerçant tape simplement :  
  > *"Rédige une description séduisante pour une robe noire de soirée élégante destinée à une clientèle haut de gamme."*

Gemini propose instantanément un texte soigné. Le commerçant peut le modifier, l'ajuster en un clic, ou l'enregistrer directement. L'IA ne remplace pas l'humain : elle lui fait gagner 20 minutes de travail répétitif !

### 2. Le catalogue des interfaces IA modernes

Voici les formes les plus courantes que peut prendre une interface IA dans un projet web :

| Type d'interface | Ce qu'elle fait pour l'utilisateur | Exemple concret |
| :--- | :--- | :--- |
| 💬 **Chat conversationnel** | Dialogue continu avec mémoire des échanges | Un assistant d'aide ou un tuteur de code |
| ✍️ **Générateur de contenu** | Rédige, résume ou reformule du texte | Création d'e-mails ou de fiches produits |
| 📊 **Analyseur de données** | Transforme du texte brut en chiffres et graphiques | Synthèse des avis clients de la semaine |
| 📝 **Formulaire intelligent** | Remplit automatiquement des champs | Déduction de l'adresse à partir d'un message |
| 👁️ **Interface multimodale** | Analyse des photos ou des fichiers PDF | Lecture automatique d'un ticket de caisse |
| 🌊 **Interface de streaming** | Affiche les mots en direct sans bloquer l'écran | L'effet "machine à écrire" fluide |

### 4. Pourquoi ne doit-on JAMAIS appeler Gemini directement depuis React ?

C'est l'erreur numéro 1 des débutants !  
Rappelez-vous : tout le code JavaScript d'un site React est **téléchargé sur l'ordinateur du visiteur**.

Si vous écrivez votre clé API Gemini dans votre code React :
1. N'importe quel visiteur curieux fait un clic droit, clique sur *"Inspecter"*, ouvre l'onglet *"Réseau"* ou *"Sources"*, et **copie votre clé en clair** en 3 secondes.
2. Un pirate peut alors utiliser votre compte pour faire des millions de requêtes gratuites à vos frais.
3. Vous perdez tout contrôle : impossible de vérifier qui pose des questions, ni de limiter le nombre de messages par minute.

<Callout type="warning" title="La règle d'or">
Le frontend ne connaît **jamais** votre clé API. Il parle uniquement à votre propre serveur backend, qui lui seul détient la clé secrète dans son fichier `.env`.
</Callout>

### 5. Les responsabilités du Frontend IA

Le rôle de React ne consiste pas seulement à afficher un pavé de texte brut. Une bonne interface IA doit :
- **Rassurer l'utilisateur** : afficher une animation discrète pour montrer que l'IA réfléchit.
- **Diffuser les mots en direct (Streaming)** : afficher le texte au fur et à mesure pour éviter que l'écran semble gelé.
- **Gérer les erreurs avec bienveillance** : si Internet coupe ou si Google met trop de temps, afficher un message d'explication clair avec un bouton *"Réessayer"*.
- **Permettre d'annuler** : si l'IA part dans une réponse trop longue, l'utilisateur doit pouvoir cliquer sur un bouton *"Arrêter"*.
- **Mettre en valeur le résultat** : afficher de jolis badges, des boutons de copie et des blocs de code colorés (UI générative).

### 6. Atelier interactif : La machine à états d'un composant React

Dans une interface IA, un bouton ou un encart de texte passe successivement par plusieurs étapes :  
*En attente (idle)* ➔ *Envoi et vérification* ➔ *Génération en cours (loading/streaming)* ➔ *Succès ou Erreur*.

#### Modèle de code pour démarrer facilement :
```tsx
import React, { useState } from 'react';

type InteractionStatus = 'idle' | 'loading' | 'success' | 'error';

export const PromptSimulator: React.FC = () => {
  const [prompt, setPrompt] = useState('');
  const [status, setStatus] = useState<InteractionStatus>('idle');
  const [errorMessage, setErrorMessage] = useState('');
  const [response, setResponse] = useState('');

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();

    // 1. Vérification : texte non vide
    if (!prompt.trim()) {
      setStatus('error');
      setErrorMessage('Merci d\'écrire votre question avant de cliquer sur Envoyer.');
      return;
    }

    // 2. Vérification : taille maximale
    if (prompt.length > 500) {
      setStatus('error');
      setErrorMessage('Votre question est un peu trop longue (500 caractères maximum).');
      return;
    }

    // 3. Tout est bon : on passe en mode chargement
    setStatus('loading');
    setErrorMessage('');

    // On simule une attente de 2 secondes
    setTimeout(() => {
      setStatus('success');
      setResponse("Voici une excellente idée rédigée par l'intelligence artificielle pour répondre à votre besoin !");
    }, 2000);
  };

  return (
    <form onSubmit={handleSubmit} className="p-6 border border-slate-200 rounded-2xl bg-white space-y-4 shadow-sm max-w-xl mx-auto">
      <label className="block text-sm font-semibold text-slate-800">
        Votre demande à l'assistant IA :
      </label>

      <textarea
        value={prompt}
        onChange={(e) => setPrompt(e.target.value)}
        disabled={status === 'loading'}
        placeholder="Posez votre question en quelques mots..."
        className="w-full p-3 border border-slate-300 rounded-xl focus:border-indigo-500 focus:outline-none"
        rows={4}
      />

      <div className="flex justify-between items-center text-sm text-slate-500">
        <span>{prompt.length} / 500 caractères</span>
        <button
          type="submit"
          disabled={status === 'loading' || !prompt.trim()}
          className="px-5 py-2.5 bg-indigo-600 text-white rounded-xl font-bold hover:bg-indigo-700 disabled:opacity-50 transition"
        >
          {status === 'loading' ? 'Génération en cours...' : 'Envoyer'}
        </button>
      </div>

      {status === 'error' && (
        <div className="p-3 bg-red-50 text-red-700 rounded-xl border border-red-200 text-sm">
          ⚠️ {errorMessage}
        </div>
      )}

      {status === 'success' && (
        <div className="p-4 bg-emerald-50 text-emerald-900 rounded-xl border border-emerald-200 text-sm space-y-2">
          <strong>Réponse de l'IA :</strong>
          <p>{response}</p>
          <button
            type="button"
            onClick={() => { setPrompt(''); setStatus('idle'); }}
            className="text-xs text-emerald-700 underline font-semibold mt-2"
          >
            Poser une nouvelle question
          </button>
        </div>
      )}
    </form>
  );
};
```
